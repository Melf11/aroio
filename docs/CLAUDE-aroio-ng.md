# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

aroio-ng builds the AroioOS firmware image (an audio streaming/DSP appliance OS) for Raspberry Pi 2/3/3B+ (32-bit ARM, Cortex-A53, glibc, systemd) using **Buildroot 2020.02** plus a `BR2_EXTERNAL` tree.

- `buildroot/` — a **vendored, locally modified** copy of Buildroot (not a submodule). Some upstream packages were patched in-tree (e.g. `bluez5_utils`, `bluez-alsa`, `rust`, `squeezelite`). Change it only when a package can't be overridden from `aroio/`.
- `aroio/` — the BR2_EXTERNAL tree (`name: aroio`, referenced as `$BR2_EXTERNAL_aroio_PATH`). Nearly all Aroio-specific work goes here.
- `docker/` — Ubuntu 18.04 build container (the host toolchain Buildroot 2020.02 expects).

## Build commands

Configure (from `buildroot/`; the output dir can be anywhere):
```
cd buildroot
make BR2_EXTERNAL=../aroio O=../output aroio_defconfig
```
Build (from the output dir): `make`. The SD card image ends up in `<output>/images/`.

Other common Buildroot targets, run in the output dir:
- `make menuconfig` — change configuration; then `make savedefconfig` to write it back to `aroio/configs/aroio_defconfig`
- `make linux-menuconfig` — kernel config (custom config file: `aroio/boards/RaspberryPi/linux-config`)
- `make <pkg>-rebuild` / `make <pkg>-dirclean` — rebuild or clean a single package
- `make` again after editing `aroio/overlay/` — the overlay is re-copied at the end of each build; no package rebuild needed

The defconfig uses paths relative to `buildroot/` (`../aroio/...`), so always run the configure step from inside `buildroot/`.

Docker build (from repo root, see `docker/README.md`): `docker build -t aroio docker/`, run with the repo bind-mounted to `/home/docker/workdir`, then `su docker` and run the commands above. ccache lives in `workdir/.ccache`.

There is no test suite; verification means building the image and booting it on hardware.

## Architecture

### Image composition (`aroio/configs/aroio_defconfig`)
- Kernel: Raspberry Pi kernel from a pinned GitHub tarball, patched with `aroio/boards/RaspberryPi/kernel_patches/` (AroioDAC clock driver).
- Post-build: upstream `board/raspberrypi3/post-build.sh`. Post-image: `aroio/boards/RaspberryPi/post-image.sh`, which **overwrites `config.txt` and `cmdline.txt`** (device-tree overlays: hifiberry-dacplus, i2s-mmap, gpio-ir, onboard wifi/bt disabled, etc.) and then runs genimage with `genimage-RaspberryPi.cfg`.
- Busybox config: `aroio/busybox/busybox.config`. Extra users: `aroio/user_sftparoio`.

### Custom packages (`aroio/package/`)
`aroio/external.mk` auto-includes every `package/*/*.mk`, but each package must also be `source`d in `aroio/Config.in` to be selectable. Most entries are Perl CPAN deps for Logitech Media Server (`slimserver`). Audio-relevant ones: `brutefir` (FIR convolution DSP), `fftw3f`, `jack-connect-persistent`, `jack_minimix`, `squeezelite-jack`, `spotifyd`, `librespot`, `alac-decoder`, `ldacbt`, `logsweep` + `filter` (room measurement & filter tarballs from `aroio/Logsweep`, `aroio/filter`). `aroio-ui` and `webinterface` fetch external git repos (Flask / FastAPI UIs); `webinterface` deletes `/opt/www` on install, so it conflicts with the PHP web UI in the overlay.

### Runtime system (`aroio/overlay/`)
The overlay is where most of the device behavior lives:
- **`/boot/userconfig.txt`** (FAT boot partition) is the central user configuration — a shell-sourceable `KEY=value` file. Scripts `. /boot/userconfig.txt` directly. `usr/bin/checkuserconfig` normalizes/migrates it (legacy 3.x keys, defaults). `/boot` is mounted read-only during normal operation and remounted rw to write.
- **`usr/bin/`** — shell control scripts. `controlaudio` is the main dispatcher: it rewrites `/etc/asound.conf` and `/etc/shairport-sync.conf` via `sed` from userconfig values, then starts/stops the right systemd units based on `AUDIO_OUTPUT` (`vol-plug`, `vol-plug-ms`, `jack-bf`, `jack-bfms`) and `RAW_PLAYER`. `*-starter` scripts launch individual players (squeezelite, librespot, spotifyd, gmediarender, jack). Brutefir config is generated by `generate-brutefirconfig`; filters live in `mnt/mmcblk0p1/brutefir`.
- **`usr/lib/systemd/system/`** holds the Aroio unit files (many use `EnvironmentFile=/boot/userconfig.txt`); **`etc/systemd/system/`** enables them via `*.wants/` symlinks. Audio players are ordered after `network-online.target` (not in-script network polling).
- **`opt/www/`** — the PHP web UI (served by busybox `httpd`, config `etc/httpd.conf`, `etc/php.ini`). `functions.inc.php` holds shared helpers; pages read/write `userconfig.txt` and call the `usr/bin` scripts.
- Some script messages are in German.
